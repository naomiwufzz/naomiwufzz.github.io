  3. 2025.10 — 2026.03

    系统项目 · 核心成员

    法律工作 Agent Runtime 与 Skill 自进化

    为美国律所与企业法务的长程、多工具任务建设统一 Runtime，让执行轨迹进入失败归因、Skill 提案、沙箱回归与版本门控。

    展开项目细节
    • Memory / Context：设计四类记忆与 Write、Select、Compress、Isolate 流程；200 组长程任务中，输入 Context Token 由 10.9k 降至 5.3k。
    • 工具编排：实现 Dispatch Table、Batch Tool Calling 与 Interrupt；120 任务 × 3 轮评测中，多工具交互轮次下降 45%，端到端耗时下降 38%。
    • Skill 自进化：以 500 条隔离任务作为门控集，经 6 轮迭代，任务成功率由 48% 提升至 78%；自动归因覆盖率 83%，候选 Skill 回归通过率 65%。
    • 安全治理：加入沙箱、分级权限、Dry-run、副作用预览与 Human-in-the-loop 审批。
  4. 2025.01 — 2025.12

    模型项目 · 方案与迭代主导

    Deep Research Agent 策略后训练

    围绕法律长链路研究中的停止、检索与证据压缩决策，构建轨迹数据、偏好优化、分阶段 Agentic RL 和隔离评测流程。

    展开项目细节
    • 训练对象：基于 Qwen3-30B-A3B；约 12 万条 SFT 数据、4.8 万组偏好对，覆盖 Planner、Researcher、Compaction 与 Reporter 等关键节点。
    • 训练阶段：CPT、SFT / DPO、GSPO / OPD、Reward / Judge；从短上下文节点训练衔接至最长 64k 的完整轨迹优化。
    • 评测结果：600 项独立测试集上研究综合分由 61% 提升至 72%；LLM-as-Judge 与专家一致性由 60% 提升至 78%。
    • 质量约束：引用重复率由 22% 降至 9%，未引用主张比例由 13% 降至 1%。

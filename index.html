  1. 2025.01 — 2025.12

    Post-training · Agent Policy

    Deep Research Agent 策略后训练

    针对法律研究中“过早停止 / 过度执行”的决策失准，围绕关键节点偏好和长程轨迹优化 Agent Policy。

    61% → 72% 600 项独立测试集综合分

    背景、职责与评测
    • 问题：闭源模型在法律长链路任务中会过早结束或过度执行，带来质量和 Token 成本波动。
    • 个人工作：主导 Agent Policy 后训练方案设计与迭代，重点负责轨迹数据构造、关键节点偏好优化、分阶段 Agentic RL、Reward / Judge 校准及隔离评测。
    • 训练对象与数据：Qwen3-30B-A3B；约 12 万条 SFT 数据、4.8 万组偏好对，覆盖 Planner、Researcher、Compaction、Reporter 节点。
    • 训练课程：CPT、两阶段 DPO、短上下文节点 GSPO / OPD，再到沙盒中的长上下文端到端轨迹优化，最长 64k Context。
    • 行为结果：DPO 后首轮不调用工具比例 75.4% → 16.0%；整体课程训练后，报告事实性 +18%、完整性 +8%。
    • 独立评测：固定语料、工具与预算的 600 项测试集，研究综合分 61% → 72%；Judge 与专家一致性 60% → 78%。
    • Reward 约束：加入引用多样性与实质信息贡献约束后，引用重复率 22% → 9%，未引用主张比例 13% → 1%。
  2. 2025.10 — 2026.03

    Agent Runtime · 核心成员

    长程 Agent Runtime 与 Skill 自进化

    把工具编排、长程记忆和 Skill 回归接入同一条可追踪执行链，解决复杂法律任务中的调度耦合与迭代缺少门控问题。

    48% → 78% 500 条隔离任务 · 6 轮迭代

    背景、职责与评测
    • 问题：长程法律任务涉及多工具调用，原有循环扩展困难；上下文持续增长；新增 Skill 缺少统一回归与发布门槛。
    • 个人工作：作为核心成员参与 Harness 链路建设，重点负责工具编排、Memory / Context、Skill 自进化及评测回归。
    • Runtime：设计 Dispatch Table 动态注册、Batch Tool Calling 和 Interrupt 恢复；新增工具平均约 30 行即可接入核心循环。
    • Memory / Context：构建用户画像、用户规则、项目记忆、轨迹经验四类记忆，以及 Write / Select / Compress / Isolate 流程。
    • Skill 闭环：轨迹分析 → 失败归因 → Skill 提案 → 沙箱回归 → 门控集成；500 条隔离任务、固定模型和工具版本，经 6 轮迭代，成功率 48% → 78%，自动归因覆盖率 83%，候选 Skill 回归通过率 65%。
    • 效率评测：200 组长程法律任务（平均 40+ 轮）中，平均每次模型调用输入 Context Token 10.9k → 5.3k（−51%）；另在 120 任务 × 3 轮评测中，多工具任务 LLM 交互轮次 −45%，端到端耗时 −38%。
    • 生产治理：沙箱隔离、分级权限、安全扫描、Dry-run、副作用预览和 Human-in-the-loop 门禁；按 Session 记录执行 Trace。
  3. 2023.02 — 2025.03

    Agentic Search · 核心成员

    Legal Deep Research Agent

    把开放式法律问题转成有覆盖计划、动态补研和逐条证据校验的长程研究流程。

    检索 F1：0.67 → 0.82 固定多跳法律评测集

    背景、职责与评测
    • 问题：传统对话检索难以处理长程研究中的目标漂移、重复检索、覆盖遗漏和证据链零散。
    • 个人工作：作为核心成员参与整体方案，主导双层 Research Control；负责长程目标锚定、动态收敛、Agentic Search、Evidence State 与引用验证。
    • 研究控制：Global Controller + Workstream Research Loop；用 Coverage Map、Workstream Ledger、Objective–Finding 校验与 Dynamic Replanning 管理覆盖、缺口和预算。
    • 检索与证据：结合 GraphRAG、引用关系和权威信号；以 Source → Passage → Finding → Claim 管理证据，并由 Verifier 与 Citation Verifier 执行分级修复。
    • 控制效果：任务通过率提升 6pp，重复研究轮次降低 20%。
    • 检索结果：固定多跳评测集 F1 0.67 → 0.82；事实一致性 0.9，检索精确率 0.7。
    • 端到端评测：90 项专项集核心评分要点通过率 58% → 73%；引用首轮失败修复率 64%，幻觉率降低 36%。
